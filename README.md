# Algorithmic Methods of Data Mining — Homeworks

This repository contains the homework assignments completed for the **Algorithmic Methods of Data Mining (ADM)** course, academic year 2026/2027.

## Repository Structure

Each homework is organized in a dedicated directory containing:

- `README.md` — Assignment overview and documentation.
- `scripts.py` — Python implementations and exercise solutions.
- `printouts/` — HackerRank submission reports and supporting evidence.
