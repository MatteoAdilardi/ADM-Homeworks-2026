# Algorithmic Methods of Data Mining — Homeworks

This repository contains the homework assignments for the **Algorithmic Methods of Data Mining (ADM)** course, academic year 2026/2027.

The assignments focus on developing practical programming skills, strengthening Python fundamentals, and implementing algorithmic solutions through HackerRank challenges.

## Repository Structure

Each homework is organized in a dedicated directory containing:

- `README.md` — Assignment overview and documentation.
- `scripts.py` — Python implementations and exercise solutions, organized by topic.
- `printouts/` — HackerRank submission reports in PDF format.

## Homework 1 — Contents

Homework 1 is divided into two main parts.

### Problem 1 — Python Challenges

The solutions are organized into the following categories:

1. Introduction
2. Basic Data Types
3. Strings
4. Sets
5. Collections
6. Date and Time
7. Exceptions
8. Built-ins
9. Python Functionals
10. Regex and Parsing
11. XML
12. Closures and Decorations
13. NumPy

These exercises cover fundamental programming concepts, data structures, string manipulation, regular expressions, object-oriented features, and numerical computing.

### Problem 2 — Algorithmic Challenges

The following HackerRank challenges are implemented:

1. Birthday Cake Candles
2. Number Line Jumps (Kangaroo)
3. Viral Advertising
4. Recursive Digit Sum
5. Insertion Sort — Part 1
6. Insertion Sort — Part 2

These exercises focus on problem-solving, iterative algorithms, mathematical reasoning, and sorting techniques.

## Code Organization

All solutions for each homework are collected in a single `scripts.py` file, grouped by category and identified by their corresponding HackerRank challenge names.

Each solution is intended to be executed independently using the input and output specifications provided by HackerRank. The combined file serves as a collection of solutions rather than a single executable program.

## Submission Documentation

The `printouts/` directory contains PDF reports documenting the submissions made on HackerRank.
